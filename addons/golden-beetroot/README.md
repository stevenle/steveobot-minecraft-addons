# Golden Beetroot

Adds the Golden Beetroot, a food that fills **7.5 hunger** (15 hunger points)
with golden-carrot-grade saturation.

## Crafting

Eight gold nuggets around a beetroot, on a crafting table:

```
[ N ] [ N ] [ N ]
[ N ] [ B ] [ N ]
[ N ] [ N ] [ N ]
```

`N` is a gold nugget and `B` is a beetroot. The recipe unlocks in the recipe
book once you have picked up a beetroot.

## Checking it is installed

Run `/scriptevent steveo:beetroot`. If the add-on is active it puts a Golden
Beetroot in your inventory and answers in chat.

## Art

The item and pack icons come from `assets/generate.mjs`:

    node addons/golden-beetroot/assets/generate.mjs addons/golden-beetroot
