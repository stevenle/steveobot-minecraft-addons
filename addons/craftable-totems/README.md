# Craftable Totems

Makes the Totem of Undying craftable, so it no longer has to come from
evokers.

## Crafting

Eight gold ingots around an emerald block, on a crafting table:

```
[ G ] [ G ] [ G ]
[ G ] [ E ] [ G ]
[ G ] [ G ] [ G ]
```

`G` is a gold ingot and `E` is an emerald block. The result is the vanilla
Totem of Undying, so it works exactly like one dropped by an evoker. The
recipe unlocks in the recipe book once you have picked up an emerald block.

## Checking it is installed

Run `/scriptevent steveo:totems`. If the add-on is active it answers in chat
with the recipe.
