# Warp Whistle

A fast-travel whistle for Minecraft Bedrock, in the spirit of the warp
whistle from *Super Mario Bros. 3*. Blow it, a tune plays, sparkles whirl up
around you, and a moment later you are somewhere else. Home is always your
bed; the rest of the list is a set of shared waypoints that everyone in the
world can set and use.

## Crafting

At a crafting table:

```
_ G _
G E G
_ F _
```

`G` is a gold ingot, `E` an ender pearl, `F` a feather, `_` empty. The
whistle never breaks.

## Using it

| Input | Effect |
|---|---|
| **Use** (right-click / tap) | Opens the warp menu |
| **Crouch + Use** | Sets a new waypoint where you stand |

The menu lists, in order:

1. **Home** — your bed (or respawn anchor). It is read from your spawn point
   every time, so it follows wherever you last slept. If you have no bed yet
   the button says so and warping does nothing.
2. **Waypoints** — every shared waypoint, with its coordinates and, outside
   the Overworld, its dimension.
3. **Set a waypoint here** — asks for a name and saves your current spot and
   facing. There is no limit on how many waypoints the world holds; names
   are up to 24 characters and must be unique.
4. **Manage waypoints** — pick a waypoint to warp to it, rename it, move it
   to where you stand, or delete it (with a confirmation).

Picking a destination starts a two-second wind-up: the whistle plays its tune
and sparkles spiral upward around you. Then you are teleported, across
dimensions if needed, facing the way the waypoint was set. The whistle then
rests for five seconds.

Waypoints are shared by everyone in the world and saved with it, so they
survive restarts and Realm uploads. Home is personal.

Using the whistle on a chest, bed, door, lever, crafting table, or anything
else you can click opens or uses that block instead of the warp menu. The same
goes for villagers, horses, boats, and minecarts.

## Debug commands

Chat is the only console on a Realm, so the add-on answers to a script event:

```
/scriptevent steveo:warp give    # put a whistle in your inventory
/scriptevent steveo:warp list    # print Home and every waypoint
/scriptevent steveo:warp clear   # delete every waypoint in the world
/scriptevent steveo:warp demo    # play the wind-up effect without warping
```

## Files

| Path | What it is |
|---|---|
| `behavior_pack/items/warp_whistle.json` | The item: icon, name, cooldown category |
| `behavior_pack/recipes/warp_whistle.json` | The crafting recipe |
| `resource_pack/textures/items/warp_whistle.png` | 16×16 icon, generated by `assets/generate.mjs` |
| `resource_pack/texts/en_US.lang` | Every player-facing string |
| `src/main.ts` | Menus, waypoint storage, and the warp effect |

Regenerate the icons with `node addons/warp-whistle/assets/generate.mjs addons/warp-whistle`.
